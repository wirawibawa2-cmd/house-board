# House board

Read-only 2D floor plan. Kai, Scout, CHAOS, RED, BLUE, and Sentry roam the house.

This is not the FOMO trading board. There is no market panel, cash, pot, or scanner here.

Open `index.html`, or visit https://wirawibawa2-cmd.github.io/house-board/ after GitHub Pages publishes from `main`.

The plan is a flat top-down schematic: living room, bedroom, kitchen, bathroom, hall, and outdoor pool. The six units walk through the doorways, bounce off walls, and slide past each other.
